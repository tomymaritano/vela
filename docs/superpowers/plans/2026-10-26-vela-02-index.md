- [ ] **Step 3: Implement the shared builder**

```rust
use ignore::{WalkBuilder, WalkState};
use std::path::{Path, PathBuf};
use std::sync::Arc;

use crate::files::{Entry, EntryKind, FileError};

const SKIP_DIRS: &[&str] = &[".git", "node_modules", "target", "dist"];

pub fn builder(root: &Path) -> WalkBuilder {
    let mut walk = WalkBuilder::new(root);
    walk.hidden(false)
        .git_ignore(true)
        .parents(true)
        .follow_links(false)
        .filter_entry(|entry| {
            let name = entry.file_name().to_string_lossy();
            if entry.path_is_symlink() {
                return false;
            }
            if entry.file_type().map(|t| t.is_dir()).unwrap_or(false)
                && SKIP_DIRS.contains(&name.as_ref())
            {
                return false;
            }
            true
        });
    walk
}

pub fn list_dir(root: &Path, directory: &Path) -> Result<Vec<Entry>, FileError> {
    let directory = crate::files::normalize_inside(root, directory)?;
    let mut entries = Vec::new();
    for dent in builder(&directory).max_depth(Some(1)).build() {
        let dent = match dent {
            Ok(d) => d,
            Err(_) => continue,
        };
        if dent.depth() == 0 {
            continue;
        }
        let name = dent.file_name().to_string_lossy().into_owned();
        let rel = dent
            .path()
            .strip_prefix(root)
            .map_err(|_| FileError::OutsideWorkspace)?;
        let path = rel
            .components()
            .map(|c| c.as_os_str().to_string_lossy())
            .collect::<Vec<_>>()
            .join("/");
        let kind = if dent.file_type().map(|t| t.is_dir()).unwrap_or(false) {
            EntryKind::Dir
        } else {
            EntryKind::File
        };
        entries.push(Entry { name, path, kind });
    }
    entries.sort_by(|a, b| a.name.cmp(&b.name));
    Ok(entries)
}

pub fn walk_files(root: &Path, cancel: Arc<std::sync::atomic::AtomicBool>) -> (Vec<String>, u64) {
    let mut files = Vec::new();
    let mut skipped = 0u64;
    builder(root).build_parallel().run(|| {
        let cancel = Arc::clone(&cancel);
        Box::new(move |result| {
            if cancel.load(std::sync::atomic::Ordering::Relaxed) {
                return WalkState::Quit;
            }
            match result {
                Ok(dent) => {
                    if dent.file_type().map(|t| t.is_file()).unwrap_or(false) {
                        if let Ok(rel) = dent.path().strip_prefix(root) {
                            let path = rel
                                .components()
                                .map(|c| c.as_os_str().to_string_lossy())
                                .collect::<Vec<_>>()
                                .join("/");
                            files_slot(&path);
                        }
                    }
                    WalkState::Continue
                }
                Err(_) => {
                    skipped += 1;
                    WalkState::Skip
                }
            }
        })
    });
    (take_files(), skipped)
}
```

pub fn walk_files(root: &Path, cancel: &std::sync::atomic::AtomicBool) -> (Vec<String>, u64) {
    let mut files = Vec::new();

Score is `1_000 - path.len()` plus `100` when the query is a contiguous substring, plus `20` when the match starts at a `/` or `_` boundary or at the start. - [ ] **Step 3: Implement search and the worker**

`search` is a pure function over `&[String]`.

The worker lives on `AppState`:

- `walk_id: AtomicU64`
- `files: Mutex<Vec<String>>`
- `cancel: Arc<AtomicBool>`
- a `tauri::async_runtime::spawn` or `std::thread::spawn` started from `open_workspace` and from `reindex`

On start: bump `walk_id`, set `cancel` for the previous walk, clear `files`, spawn the thread. The thread calls `filter::walk_files`. Every 250 ms it copies the paths gathered so far into `files` and emits `index-progress` with `{ walk_id, indexed, skipped, done: false }`. At the end it emits `done: true`.

`open_workspace` still returns root entries immediately. `walk_id` in that response is the new id. `watch_ok` stays false until Task 3.

`search_files(generation, query)` reads `files` and returns `search(...)`. An empty query returns an empty vec. The shell shows recents itself.

`reindex` bumps `walk_id` and starts a new walk. It does not change `generation`, the root, or the watcher.

Add `allow-search-files` and `allow-reindex` to the capability.

- [ ] **Step 2: Start a watcher when a folder opens**

Use `notify::recommended_watcher`. Watch the workspace root with `RecursiveMode::Recursive`. Send events through a channel. A thread sleeps 100 ms after the first event in a burst, drains the channel, drops paths that `filter::builder` would ignore, and emits one `fs-change` event:

```json
{ "paths": ["src/main.rs", "src/new.ts"] }
```

Paths are relative with `/`. If `recommended_watcher` returns an error, `open_workspace` still succeeds and `watch_ok` is false.

On folder switch, drop the watcher. `reindex` keeps it.

- [ ] **Step 3: Apply changes in the shell**

Listen with `@tauri-apps/api/event` `listen("fs-change")` and `listen("index-progress")`.

- Progress updates the status: `Indexing N files` while `done` is false, `N files` when done, `N files · M folders skipped` when `skipped > 0`.
- For each changed path, if it is the active tab and the tab is clean (`text === savedText`), call `read_file` again and replace the document. If the tab is dirty, set status to `Changed on disk: <path>` and do not replace the text.
- If a clean tab's path disappears (the read returns not found), close that tab and set status to `Deleted <path>`.
- If a dirty tab's path disappears, leave the tab. Save still calls `write_file`, which creates the file.
- Re-list every expanded directory whose relative path is a parent of a changed path.
