- [ ] **Step 3: Implement `snapshot`**

```rust
pub struct SnapshotIn {
    pub path: Option<String>,
    pub text: Option<String>,
    pub language: Option<String>,
    pub cursor_line: usize,
    pub binary: bool,
    pub too_large: bool,
}

const SNAPSHOT_LIMIT: usize = 100 * 1024;

pub fn snapshot(input: SnapshotIn) -> String {
    let Some(path) = input.path else {
        return "No file is open.".into();
    };
    if input.binary {
        return format!("{path}\nbinary\nThe body is omitted.");
    }
    if input.too_large {
        return format!("{path}\ntoo large\nThe body is omitted.");
    }
    let Some(text) = input.text else {
        return format!("{path}\nThe body is omitted.");
    };
    if text.len() <= SNAPSHOT_LIMIT {
        return format!("{path}\n{text}");
    }
    let lines: Vec<&str> = text.lines().collect();
    let center = input.cursor_line.saturating_sub(1).min(lines.len().saturating_sub(1));
    let start = center.saturating_sub(100);
    let end = (center + 100).min(lines.len());
    let window = lines[start..end].join("\n");
    let language = input.language.unwrap_or_else(|| "plain".into());
    format!("{path}\nlanguage: {language}\ncut\n{window}")
}
```

- [ ] **Step 2: Command shape**

```rust
#[derive(serde::Deserialize)]
struct Turn {
    role: String,
    text: String,
}

#[tauri::command]
async fn agent_send(
    app: tauri::AppHandle,
    turns: Vec<Turn>,
    snap: SnapshotIn,
) -> Result<(), String> {
    let key = std::env::var("XAI_API_KEY").map_err(|_| "missing XAI_API_KEY".to_string())?;
    let snapshot_text = snapshot(snap);
    let mut messages = vec![serde_json::json!({
        "role": "system",
        "content": "You are the assistant inside Vela. You can see only the attached snapshot. You cannot modify files or run commands. Answer in the language of the latest user message.\n\n"
    })];
    // Append the snapshot as the last user context, then the turns.
    // Keep at most the last 20 turns. The shell also trims, this is the backstop.
    let start = turns.len().saturating_sub(20);
    for turn in &turns[start..] {
        messages.push(serde_json::json!({ "role": turn.role, "content": turn.text }));
    }
    messages.push(serde_json::json!({ "role": "user", "content": snapshot_text }));
    // POST https://api.x.ai/v1/chat/completions
    // model: "grok-4.7"
    // stream: true
    // Do not set search tools.
    // On each SSE delta, app.emit("agent-delta", { "text": chunk }).
    // On end, app.emit("agent-done", {}).
    // On HTTP or network failure, return Err with the status only.
    // Do not log messages, snapshot_text, or the response body.
    // Log at most: "agent request failed" and the status code.
    Ok(())
}
```

Replace the comment block with the real `reqwest` stream loop before committing. Read SSE lines that start with `data: `, skip `[DONE]`, parse the JSON, and emit `choices[0].delta.content` when it is a string. A new `agent_send` or a `agent_cancel` command sets an `AtomicBool` that the loop checks between chunks. The shell calls `agent_cancel` on Stop and before a new send.

Add `allow-agent-send` and `allow-agent-cancel` to the capability.

- [ ] **Step 1: Transcript state**

```ts

transcript: Message[];

```

`openFolder` sets `transcript: []` and calls `agent_cancel` if `streaming`. `reindex` does not touch `transcript`.

`sendAgent(text)` appends the user message, appends an empty assistant message, sets `streaming`, and invokes `agent_send` with the last 20 messages and a snapshot:

| Active tab | Fields sent |
|---|---|
| Text, `text.length <= 100 * 1024` | path, text, language, cursor line 1 if unknown |
| Text, longer, up to the open document | path, text, language, cursor line. Rust cuts it |
| Notice `binary` or `too_large` | path, `binary` or `too_large`, no text |
| No tab | all empty |

Listen for `agent-delta` and append to the last assistant message. Ignore deltas when `streaming` is false. `agent-done` sets `streaming` false. A thrown invoke sets status to the error and leaves the user message in the transcript.

`stopAgent` sets `streaming` false and invokes `agent_cancel`.

`newConversation` cancels and sets `transcript` to `[]`.
